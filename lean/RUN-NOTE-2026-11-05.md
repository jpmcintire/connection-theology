## 1. The occasion

The weighting clause of 10-20 has two halves: a weighting is a claim about the stake weighted, and its reason has to be about the dependencies. vM put the first half in the type and took the second as "tracks size" — a reason that gives the same verdict for any two stakes of one size — because in the base frame `M` is a bare type and size is the only handle on the dependencies there. The run note said the restatement was owed: §12a (3)'s region frame makes the size *be* the dependencies (`M := Region Step`, a stake's magnitude the set of steps hanging on its edge), so the clause's own phrase can be said there and checked against the handle vM used. That is this run. The shelf exercise (11-4/11-5) added the second item: the dilemma that closes the lab result had been two theorems, `size_reason_no_discount` and `discount_for_reason_is_partial`, and a reader of the shelf note is told it is one dilemma with no third thing; the file should say that as one statement.

## 2. What changed in the file

**§12c, one definition and nine theorems, no new carrier.** `AboutTheDependencies P` — a reason on stakes is about the dependencies when its verdict is a function of the stake's magnitude and of nothing else: not the holder, not the reader's position, not the hour. In the base frame that reads "a function of the size"; in the region frame it reads literally.

`about_deps_tracks_size` — a reason about the dependencies gives one verdict to two stakes of one size; vM's hypothesis, derived from the definition. `about_deps_no_discount` — the first horn restated: such a reason never yields a discount. `discount_dilemma` — the dilemma as one theorem: for any reason and any discount it yields (two stakes of one size, the reason on one and not the other, the hand open on the one without it and closed on the one with it), the reason is not about the dependencies *and* the reader is partial. The two horns are the two conjuncts; what the one statement excludes, for every reason at once, is the third thing — a reason that yields a discount and is about the dependencies.

In the region frame (`section RegionReason`): `ofRegion Q` lifts a reason stated on regions — on what hangs on an edge — to the stakes of the region frame; `ofRegion_about_deps` — such a reason is about the dependencies by definition; `region_reason_no_discount` — the restatement owed: in the frame where size is the region, a reason that is a function of what hangs on the edge never yields a discount, so "tracks size" and "about the dependencies" are one hypothesis there. `edgeOf` builds an edge from a step, its magnitude `hangsOn Dep a`; `ofRegion_edge` — on such an edge a reason about the dependencies is `Q (hangsOn Dep a)`, a function of what hangs on the edge, by `rfl`: the sentence the run note owed, as a definitional equality. `holderReason me` — a reason that reads who holds the edge; `holder_reason_not_about_deps` — as soon as two holders can share a region, that reason is not a function of the region: the same dependencies, two verdicts. "Mine" is such a reason (link 7). Toy, in the two-step world as a region frame: "the edge reaches step b" is about the dependencies; "the holder is a" is not, because ⟨a, onlyB⟩ and ⟨b, onlyB⟩ share a region.

**Prose.** A vO paragraph in the header; §12c's own paragraph; §13: vO adds none — a predicate on reasons and a lift, no new carrier; what it shows is that the clause's phrase and vM's handle are one hypothesis where size is the region, and that the dilemma is one theorem; the loss it inherits is §12a (3)'s, declared there — the region keeps which steps go differently and drops how much.

## 4. What the run settles, and what it does not

**Settles.** That "about the dependencies," said in the frame where size is the region, is the same hypothesis vM used under the name "tracks size," so the restatement owed is not a second formalization standing beside the first but the first read where it means what it says. That the dilemma closing the lab result is one theorem, with the third thing excluded for every reason by one statement rather than left to the reader to assemble from two. And one small thing the shelf had said in prose: a reason that reads the holder — "mine" — is not about the dependencies, as a theorem, as soon as two holders can share a region.

**Does not settle, and does not claim.** The region representation drops degree (`region_forgets_degree`, vJ), and the restatement inherits that loss: a reason about *how much* things go differently is not a function of the region and is not captured here. The paper owns this ("counting, not quantity"); the file does not pretend otherwise. And `AboutTheDependencies` is a definition — the file's statement of the clause's phrase, checkable for what it says, not a theorem that the phrase means this. The critic who thinks "about the dependencies" means something other than "a function of what hangs on the edge" should say what, and this definition is where to say it.
